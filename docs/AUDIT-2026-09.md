# Audit: September 2026

A correctness, efficiency and cruft pass over the whole workspace after a period
without work. Every fix below landed with a regression test that fails before it
and passes after, unless the row says otherwise; the commit message of each fix
carries the full reasoning (`git log --grep` on the component). Open items that
need a design or format decision are listed at the end and in
[`ROADMAP.md`](ROADMAP.md).

## Baseline

`make ci` was red on Linux at `d61e73e`: rustfmt drift, two broken rustdoc links
(one only visible on Linux), and the drive-pipe drain-bound test, whose 8 KiB input
fits Linux's pty buffer and so never reached the bound. There was no hosted CI, so
none of this had been seen. Now: `.github/workflows/ci.yml` runs `make ci` on Linux
on every push, and `make test`, `make clippy` and `make doc` each cover both the
default and the all-features configuration.

Efficiency: frame CRC is slicing-by-8 (~4x); `Filter` matching allocates nothing,
including on the broker's per-record fan-out path; the fold has no per-escape
allocation and linear animation; deliveries are framed in place and written in
64 KiB batches (fan-out ~1.5–2x); group commit writes one syscall per batch; tail
catch-up and fork snapshots copy a bounded chunk per lock hold (a 1M-record
catch-up held the lock ~23 ms, now ~44 µs per chunk); the pty drain buffer and
several recovery paths lost quadratic or duplicate copies.

Cruft: history narration trimmed from comments across every crate; the README's
evidence table shrank from 216 KB to ~85 KB by condensing claim texts to what each
command verifies; the SSH redirect stub and the built effects seed were deleted;
`ROADMAP.md` became a list of open work; test files named after audit rounds or
audit scopes (`r2_…`, `core2_…`) were renamed to their subjects; unused workspace
dependencies, dead pub items and duplicated helpers were removed.

## Open, by decision

These need a design or on-disk format decision rather than a local fix.

- **At-rest records bind to their index, not their log**: two logs under one key
  can have same-index records swapped undetected. Use one key per log.
- **Retention cannot carry producer bindings or pending wills** across compaction,
  so it refuses to drop them; on a guarded broker that stops it early in the log.
- **A power-loss tail of zeroed extents reads as corruption**: open refuses and
  needs `asb repair` although only an unacked batch was torn.
- **A blackholed follower costs up to `REPLICA_IO_TIMEOUT` per batch**, because down
  followers are re-dialed on every batch; a backoff would change documented behavior.
- **DECSC/DECRC do not save the SGR pen** (xterm and aterm do); changing it changes
  `Screen::serialize` and every frame hash.
- **The evidence runner has no per-claim timeout**; a hung claim is bounded by the
  CI job timeout and, with results streamed, is visible by name.
- **`evidence/verify/trust-wire.md` is stale** for the CRC and `Filter` functions
  rewritten here; re-running it needs the pinned Trust toolchain.
- Hardening the code does not claim: the `SealedStream` key is not zeroized on drop,
  and an OS CSPRNG failure panics rather than returning an error.
