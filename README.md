# astream

A small, reproducibly-buildable, agent-native message bus. The successor to kafka2.

- **License:** Apache-2.0
- **Status:** 13 crates. Every claim in
  [`evidence/manifest.toml`](evidence/manifest.toml) is re-run by `make ci`, which
  is run on both Linux and macOS. What is built: a deterministic record/replay terminal substrate
  that is also a *servable*, offset-addressed bus — durable exactly-once pub/sub +
  resume over a Unix socket and TCP; opt-in XChaCha20-Poly1305 sealing (pre-shared
  key, forward-secret X25519 handshake, or mutual Ed25519 identity); opt-in
  capability enforcement on the accept path, with expiry; opt-in encrypt-at-rest,
  anti-rollback and retention for the durable log; a live PTY host; a pump that
  wakes a turn-based agent on semantic boundaries from any subject, off a
  broker-durable cursor; and two CLIs (`asb`, `aspump`). Open work is in
  [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Why this exists

astream is a deliberate response to a skeptical audit of **kafka2**, a
252,000-line message bus built by an autonomous agent swarm. The audit's
verdict: the *code* was largely competent, but the *process* failed — it
shipped an artifact that did not build from a clean checkout, cited an evidence
file that did not exist, counted decorative "proofs" as rigor, and let a
templating typo silently dead-code a module.

astream's thesis is that **honesty must be a machine gate, not a matter of
diligence.** So the first increment was not a feature but the enforcement spine
every later increment is gated by:

1. **Reproducible build is the headline correctness property.** `git clone &&
   cargo test --locked` passes on a stock runner, with zero git/private
   dependencies and a committed `Cargo.lock`.
2. **Docs are generated from evidence.** The claims table below is produced by
   `astream-evidence render` from [`evidence/manifest.toml`](evidence/manifest.toml).
   A claim physically cannot cite an artifact the harness does not produce.
3. **The merge gate makes kafka2's failures un-mergeable.** `astream-evidence
   gate` rejects: git dependencies, cfg references to undeclared features
   (the dead-code-by-typo class), incomplete / session-drift checkpoint
   markers, unlinked task notes, constant-only tests, a stale generated README,
   and any verification crate wired into the substrate workspace.

The thesis, architecture, and performance doctrine live in
[`docs/DOCTRINE.md`](docs/DOCTRINE.md): determinism as a replay substrate, the
Pareto rule (never worse on a measured axis), the durability dial, and the
benchmark-regression gate. Performance is a labeled durability *dial*, not a
fixed posture; "never worse on a measured axis" is enforced by `bench`-kind
claims, not asserted.

## Layout

```
crates/astream-wire/      pure vocabulary: Frame codec (CRC-32), Subject/Filter
                          (+ Filter::contains), assign_partition, Offset. Zero
                          dependencies, no I/O, panic-free on hostile input.
crates/astream-evidence/  the honesty harness: manifest runner, README
                          generator, and the merge-gate lints.
crates/astream-term/      the pure VT screen fold (DECSTBM, bce), records,
                          speculative echo, perceive/render, semantic events.
crates/astream-engine/    the per-partition single-writer Log over the effect
                          seam: replay, Strict durability, resume, fork,
                          fleet consistent cut, ControlToken, durable execution.
crates/astream-host/      the live PTY host + Driver; the workspace's two
                          unsafe cordons (`sys`, cfg(unix); `foreign`, the
                          cfg(linux) ptrace tracer).
crates/astream-effects/   the Effects rung: EffectSeam / ReplaySeam + EffectsLog.
crates/astream-agent/     the Cognition rung: the agent turn log, hermetic
                          replay, cog_fork_swap, the unified four-stream capstone.
crates/astream-live/      the zero-dep live-capture bridge (`capture` binary).
crates/astream-broker/    the servable bus: UDS + TCP, group commit, pipelining,
                          sharding, the durability dial, Replicated tier, the
                          fabric verbs (Last/Fetch/Will/inbox); opt-in `cap`,
                          `aead`/`handshake`/`identity`, `at-rest`,
                          `anti-rollback`, `retention` features; the `asb` CLI.
crates/astream-cap/       the HMAC-SHA256 capability mint (vetted sha2 only).
crates/astream-aead/      XChaCha20-Poly1305 seal/open + SealedStream, the X25519
                          handshake and Ed25519 identity (vetted RustCrypto
                          primitives, isolated here).
crates/astream-kafka/     Kafka wire-protocol handshake + Metadata (v0 codec).
crates/astream-pump/      the drive-pipe pump (fold -> classify -> wake) on any
                          subject, off a client-held or broker-durable-group
                          cursor; opt-in `aead`; the `aspump` CLI.
evidence/manifest.toml    the single source of truth for every claim.
evidence/bench/           attached cross-system bench artifact (vs Redis).
evidence/verify/          attached Trust verification artifact.
scripts/                  verify-trust.sh, bench-vs-redis.sh (re-run the
                          attached artifacts; neither is a make-ci claim).
docs/                     DOCTRINE, GOAL, ROADMAP, the design records, and
                          AUDIT-2026-09 (the last whole-tree audit).
```

Verification under the Trust compiler (a `rust-lang/rust` fork whose SMT verifier
runs as a MIR pass during compilation) is an **attached survey, not a claim**:
`scripts/verify-trust.sh` builds the real `astream-wire` library under Trust and
records the per-function verdict on every auto-generated Level-0 safety obligation
in [`evidence/verify/trust-wire.md`](evidence/verify/trust-wire.md). Trust is a
separate toolchain, never a workspace dependency, so a broken verifier can never
break the substrate build (the exact kafka2 failure); the gate enforces this.

## Quick start

```bash
make ci                                   # the whole gate: fmt, build, test (twice), gate,
                                          # clippy, rustdoc, and every manifest claim
cargo test --locked --workspace           # the tests with default features ...
cargo test --locked --workspace --all-features  # ... and again with every feature on: neither
                                          # run is a superset (feature-gated tests vs the
                                          # cfg(not(feature)) fallbacks), so `make ci` runs both
cargo run -q -p astream-evidence -- gate  # the merge gate: 0 findings on this tree
cargo run -q -p astream-evidence -- run   # re-run every claim in the manifest
```

## What is not built

Open work — seeds and designs with no manifest row yet — is listed in
