# astream

A small, reproducibly-buildable message bus for agent fleets, built around deterministic record and replay.

astream is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries astream's binary releases, their release notes, and its
license.

## Install

Install it with aterm's package manager, which verifies every signed binary:

```sh
aterm pkg install astream
```

Every release is listed under [Releases](https://github.com/alabsystems/astream/releases),
and its notes are in `release-notes/`.

## Security

Report a security problem privately to hello@alab.systems, not in a public
issue.
